# Churn — AI vs Human Productivity Analysis

Reads `docs/metrics/features/*.json` and renders a visual comparison artifact showing AI time, human estimated time, cost savings, and speed multipliers per feature.

## Steps

1. **Read all feature reports**

```bash
ls docs/metrics/features/
```

Read each `.json` file with the Read tool.

2. **Aggregate the data**

For each feature file extract:
- `feature` — name
- `ai.session_hours` — actual AI time
- `human.estimated_hours` — human estimate from task specs
- `ai.cost_usd` — AI cost (tokens)
- `human.estimated_cost_usd` — human cost (hours × rate)
- `comparison.speed_multiplier` — how much faster AI was
- `comparison.cost_saved_usd` — money saved
- `tasks` — array of individual tasks with per-task estimates

If a feature file is missing `ai.session_hours` (session time wasn't recorded), use the sum of tasks' estimates divided by the speed multiplier from similar features as a fallback, and note it as estimated.

3. **Generate the artifact**

Load skill `artifact-design` then call the Artifact tool to publish an HTML page with:

### Charts to include

**Chart 1 — Hours: AI vs Human (grouped bar, per feature)**
- X axis: feature names
- Two bars per feature: AI hours (blue) and Human estimated hours (orange)
- Annotation on each bar with the value

**Chart 2 — Cost: AI tokens vs Human dev (grouped bar, per feature)**
- AI cost in USD (blue) vs human cost at dev rate (orange)
- Y axis: USD

**Chart 3 — Speed multiplier (horizontal bar)**
- One bar per feature
- Value = human_hours / ai_hours
- Color gradient: green for >5×, yellow for 2–5×, red for <2×
- Reference line at 1× ("no gain")

**Summary tiles (top of page)**
- Total hours saved across all features
- Total cost saved in USD
- Average speed multiplier
- Number of features measured

### Data format passed to the artifact

```json
{
  "features": [
    {
      "name": "auth-refresh",
      "ai_hours": 0.8,
      "human_hours": 12,
      "ai_cost_usd": 0.42,
      "human_cost_usd": 900,
      "multiplier": 15,
      "tasks": [
        { "task": "T1.1", "ai_portion_h": 0.2, "human_h": 4 },
        ...
      ]
    }
  ],
  "totals": {
    "hours_saved": 11.2,
    "cost_saved_usd": 899.58,
    "avg_multiplier": 15
  }
}
```

### Artifact requirements

- Dark-mode compatible (use CSS variables)
- Use Chart.js from cdnjs for charts
- Responsive: readable on mobile
- Summary tiles at the top before charts
- A table below the charts with raw numbers per feature
- Footer: "Generated by /churn on YYYY-MM-DD | Rate: $75/h"

4. **If no data exists yet**

If `docs/metrics/features/` is empty or has no `.json` files, explain:
- Tasks need a `Human: Xh` field in the spec
- After each task completes: `scripts/metric-logger.sh task T1.1 green 4h`
- After the feature is done: `scripts/metric-logger.sh feature-report <feature-name>`
- Then run `/churn` again

## Notes

- The hourly rate defaults to `$75/h` in `metric-logger.sh`. Teams can change `HOURLY_RATE_USD` there.
- AI session time measures wall-clock time of the Claude session, not pure coding time — it includes thinking, reading, and planning. That's intentional: human estimates include all that too.
- Tasks without a `Human:` estimate are excluded from the comparison and counted in `tasks_without_estimates`. Encourage adding estimates retroactively to the feature file's task list.
